What it does

AtelierMesh is a workflow engine for meshes. A design is a list of steps; change step 3 of 5 and only steps 3 to 5 run again.

One mesh, one closed surface

Text and drawings follow the curves of the model. There is no boolean operation and no image: the result is a clean mesh your slicer reads as it is.

For designers and customers

A designer builds the steps and chooses what a customer may change. The customer personalises one model and sees the real result.

Straight to the slicer

Export STL or 3MF, with colours and parts named so PrusaSlicer and Bambu Studio show them as you made them.

Private by default

The app runs in your browser. Files stay on your device. Nothing is uploaded unless you choose to share an example.

Plugins

Every step is an operation of a plugin. The built-in plugins do most things; anyone can write another, in plain JavaScript, with any licence they like.

Raised and engraved textSVG on the surfaceResize and rotateTwist, bend, taper, wave, rippleHoles and pocketsHollowVoronoi patternTexturesLow polyReduce trianglesRepairDelete or keep a partPrintability check

  1. Write itA manifest says what the plugin does and which settings it has. A small function does the work on the mesh.
  2. Check and pack itThe kit tests it, then packs it into one .amplugin file, with hashes and an optional signature.
  3. Load itPeople add it from a file, an address or a catalogue. The app shows who made it and what it needs, and asks first.
  4. It runs in a sandboxA plugin has no network and only sees the model it works on.
npm install
npm run build:standalone
npx --yes serve apps/standalone/dist

# a plugin of your own (needs only Node 20)
node tools/amplugin.mjs new my-plugin
node tools/amplugin.mjs check my-plugin
node tools/amplugin.mjs pack my-plugin

The plugin developer kit (MIT licence) has the guide, the Mirror example, the type declarations and the packing tool. A prompt for your coding agent is in docs/prompt-make-a-plugin.md.

Examples and a catalogue

The app can read a catalogue of plugins and a gallery of example designs from the live site. People send designs and plugins in; an admin accepts them. You can add more than one catalogue.

Open an example

Click one, change your own copy, and see how it was made. If it needs a plugin you lack, the app asks first.

Share yours

Save, then Share as an example. It appears after a quick check. Anyone may open, change and share it, naming the maker (CC BY 4.0).
